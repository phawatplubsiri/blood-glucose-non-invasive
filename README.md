# Non-invasive Blood Glucose Monitoring System

> ระบบตรวจสอบและวิเคราะห์ระดับน้ำตาลในเลือดแบบไม่เจาะจง เพื่อศึกษาและวิจัยด้านสุขภาพ

## เกี่ยวกับโปรเจกต์

โปรเจกต์นี้เป็นแพลตฟอร์มที่รวมเอาการรวบรวมข้อมูลจากเซ็นเซอร์ ESP และการวิเคราะห์ผ่านโมเดลการเรียนรู้ของเครื่อง (Machine Learning) เพื่อศึกษาและวิจัยด้านสุขภาพ

---

## จุดประสงค์

| ลำดับ | วัตถุประสงค์ |
|------|----------|
| 1. | ระบบบันทึกและจัดการข้อมูลระดับน้ำตาลจากเซ็นเซอร์ ESP แบบเรียลไทม์ |
| 2. | แสดงผลการวิเคราะห์และเปรียบเทียบประสิทธิภาพของโมเดล ML หลากหลายรูปแบบ |
| 3. | เครื่องมือจัดการฐานข้อมูลสุขภาพสำหรับพัฒนาโมเดลพยากรณ์ในอนาคต |

## ฟีเจอร์หลัก

### แดชบอร์ดและการแสดงผล
- รับค่าจากเซ็นเซอร์ ESP แบบเรียลไทม์
- แสดงข้อมูลบนแดชบอร์ดโปรแกรม

### การวิเคราะห์ด้วยโมเดล
- **CNN** - Convolutional Neural Network
- **DNN** - Deep Neural Network
- **Random Forest** - ต้นไม้แบบสุ่ม
- **Decision Tree** - ต้นตัดสินใจ
- **MLR** - Multiple Linear Regression

### การแสดงผลทางสถิติ
| ประเภท | คำอธิบาย |
|------|----------|
| Line Chart | กราฟแสดงแนวโน้มของข้อมูล |
| Scatter Chart | กราฟการกระจายตัวของข้อมูล |
| Residual Chart | กราฟค่าคงเหลือของโมเดล |
| Learning Curve | กราฟการเรียนรู้ของโมเดล |

### การจัดการข้อมูล
- เพิ่มข้อมูลใหม่
- แก้ไขข้อมูลที่มีอยู่
- ลบข้อมูลที่ไม่ต้องการ
- ส่งออกข้อมูลเป็นไฟล์ CSV

### การเชื่อมต่อภายนอก
- ลิงก์ไปยัง Google Colab สำหรับฝึกฝนโมเดล
- ลิงก์ไปยัง Google Drive สำหรับจัดเก็บข้อมูล

## การติดตั้งและใช้งาน

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันในโหมดพัฒนา (Development)
```bash
npm run dev
```
แอปพลิเคชันจะเปิดที่ `http://localhost:5173`

### 3. ตั้งค่า Firebase

#### ขั้นตอน:
1. ตรวจสอบการตั้งค่า Firebase Configuration
   ```
   📂 src/configs/firebaseConfigs.js
   ```

2. ตรวจสอบให้แน่ใจว่า Configuration ตรงกับโปรเจกต์ Firebase ของคุณ
